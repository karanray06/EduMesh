# EduMesh OpenClaw Skill

This skill allows you to connect your EduMesh account to your WhatsApp or Telegram bot via OpenClaw.

## Features
- **Ask Arya**: Send doubts directly to your AI tutor
- **Quick Quizzes**: Request 5-question pop quizzes on any topic
- **Daily Plan**: Check your today's mission

## Installation
1. Go to your EduMesh dashboard -> **Settings** -> **OpenClaw Integration**.
2. Click **Generate API Key**.
3. In your OpenClaw admin panel, install this skill and paste the API key in the configuration.
4. Set the `edumesh_url` to your hosted EduMesh instance.

## Commands
- `/doubt [question]` - Ask a specific doubt
- `/quiz [topic]` - Generate a quick quiz
- `/plan` - Get today's study plan
- `/note [topic]` - Search your smart notes
